글을 붙여 넣어 씬 여러 개 만들기

한글(HWP)·워드에 써 둔 원고를 복사해 붙여 넣으면, 문단마다 씬 하나로 나눠 이 장의 끝에 붙입니다.

작성 안내

1. 무엇을 쓰나요?

  • 과정 정보에서 맡으신 과정을 고르면 차시 수·내용전문가·검수자가 채워집니다.
  • 차시마다 장 → 씬 순서로 본문을 씁니다. 씬 하나가 화면 한 장(약 30초~2분)입니다. 장 하나는 약 5분짜리 영상 한 편이 됩니다.
  • 도입(인사·학습목표·학습내용)과 마무리(평가·학습정리·끝인사) 화면은 제작 도구가 자동으로 만듭니다. 본문, 평가 문제, 학습 정리 요점만 써 주세요.

2. 씬에 쓰는 칸

  • 핵심 내용 (필수) — 이 씬에서 꼭 설명할 내용을 개조식으로 적습니다. 대본을 직접 쓰지 않으면 AI가 이 범위 안에서만 대본을 씁니다.
  • 근거 — KEC 조항, 법령 조문, 교재 쪽수 등. 검수와 AI 대본 작성에 씁니다.
  • 화면 문구 — 화면에 띄울 짧은 구 2~4개를 줄마다 하나씩 씁니다.
  • 판서 · 강조 메모 — 전자칠판·태블릿에 쓰거나 강조할 내용 한 줄.
  • 강의 대본 (선택) — 직접 쓰시면 성우·강사가 그대로 읽습니다. 1분에 약 330자입니다.
  • 그림 (선택) — 원하는 화면을 말로 설명하거나, 직접 찍은 사진·도면을 붙입니다.

3. 화면 문구를 이렇게 쓰면 화면이 알맞게 바뀝니다

  • 기한·주기: 선임신고 | 30일 이내 → 기한 타임라인
  • 측정값과 기준: 절연저항 | 0.8 MΩ | 기준 1.0 MΩ 이상 → 계측기 화면
  • 수치 비교 2~3개: 역률 | 95 %, 부하율 | 70 % → 게이지
  • 흐름·계통: 수전설비 → 변압기 → 배전반 → 부하 → 흐름도
  • 안전 수칙: 씬 제목에 주의·금지·위험이 있으면 짧은 수칙 2~4개 → 안전 경고 화면

4. 저장과 보내기

  • 쓰는 내용은 이 컴퓨터의 브라우저에 자동으로 저장됩니다. 그래도 파일로 저장을 눌러 파일을 만들어 두세요.
  • 만든 파일(…_원고.json)을 메일 등으로 협회에 보내 주시면 됩니다. 검수자도 같은 파일을 열어 검수 의견을 적고 다시 저장해 돌려줍니다.
  • 이어서 쓰려면 원고 파일 열기로 파일을 열거나, 파일을 이 창에 끌어다 놓으세요.
  • 인쇄 · PDF로 검토용 문서를 뽑을 수 있습니다 (인쇄 창에서 "PDF로 저장" 선택).

5. 사진·그림 사용

  • 직접 찍은 사진이나 직접 그린 도면, 사용 허락을 받은 자료만 붙여 주세요. 인터넷에서 내려받은 그림은 저작권 문제가 생길 수 있습니다.
  • 사진 속 사람 얼굴·차량 번호·회사 이름이 보이면 알려 주세요.
